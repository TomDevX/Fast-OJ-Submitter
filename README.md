# Fast-OJ-Submitter
Fast submitter with keyboard shortcuts for OJs

Currently available OJs:
|                OJs               	| Status 	|
|:--------------------------------:	|:------:	|
|   [VNOJ](https://oj.vnoi.info/)  	|    ✅   	|
| [MarisaOJ](https://marisaoj.com) 	|    ✅   	|
|     [CSES](https://cses.fi/)     	|    ✅   	|
|   [SPOJ](https://www.spoj.com/)  	|    ✅   	|
|  [Atcoder](https://atcoder.jp/)  	|    ✅   	|

# 📖 How to use
- `Ctrl/Cmd + S`: submit clipboard (must be on problem page)
- `Alt/Opt + S`: submit file (must be on problem page)

# How to download

> You need to download [Tampermoney](https://www.tampermonkey.net/) or similiar tools to be able to use this script

There are 3 ways you can do:
1. Go to [source file](fast_OJ_submitter.user.js) and view it in raw mode. A Tampermonkey script installation request will be prompted
2. Paste [source file](fast_OJ_submitter.user.js) inside your tampermonkey
3. Install from [Greasy Fork](https://greasyfork.org/en/scripts/588502-fast-oj-submitter)
