# Fast-OJ-Submitter
Fast submitter with keyboard shortcuts for VNOJ, Atcoder, CSES, SPOJ

# 📖 How to use
- `Ctrl/Cmd + S`: submit clipboard (must be on problem page)
- `Alt/Opt + S`: submit file (must be on problem page)

# How to download

> You need to download [Tampermoney](https://www.tampermonkey.net/) or similiar tools to be able to use this script

There are 2 ways you can do:
1. Go to [source file](CSES-VNOI-AtCoder-SPOJ_fast_submitter.user.js) and view it in raw mode. A Tampermonkey script installation request will be prompted.
2. Install from [Greasy Fork](https://greasyfork.org/en/scripts/588502-cses-vnoi-atcoder-spoj-fast-submitter)
